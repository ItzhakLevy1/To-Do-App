# 📋 My Tasks - Task & Project Management Web App

A clean, responsive, and customizable Task & Project Management web application built with vanilla HTML5, CSS3, and JavaScript. Designed as a Progressive Web App (PWA) that offers seamless usability across desktop laptops and mobile devices.

---

## ✨ Features

- **📂 Project Management**: Create, edit, and delete custom project categories to organize your tasks efficiently.
- **🏷️ Task Filtering & Search**:
  - Full-width search bar on laptops/desktops with a single-click clear (`X`) button.
  - Filter tasks by status (_All_, _To Do_, _In Progress_, _Completed_).
- **📊 Real-time Dashboard**: Live counters for total tasks, completed tasks, in-progress tasks, and urgent priorities.
- **🌓 Dark / Light Mode**: Toggle between light and dark themes with preference persistence.
- **💾 Local Data Storage & Backup**:
  - Automatically saves all tasks and projects in `localStorage`.
  - Export your data to a `.json` backup file or restore from a previously saved file.
- **📱 PWA Support**: Installable directly to your home screen or desktop application list.
- **🌐 Fully Hebrew / RTL Ready**: Built natively with Right-to-Left (RTL) alignment.

---

## 🛠️ Built With

- **HTML5** - Semantic markup structure
- **CSS3** - CSS Custom Properties (Variables), Flexbox, CSS Grid, and responsive media queries
- **JavaScript (ES6+)** - Dynamic DOM manipulation and `localStorage` integration
- **Font Awesome v6** - UI Icons
